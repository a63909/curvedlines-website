# КАДР

Статический кинотеатр для браузера и Mayday. Ноябрьские премьеры собраны в отдельной витрине. Архив, поиск и «Смотреть позже» используют общий каталог. Закладки сохраняются на устройстве.

Фильмы с открытым встраиванием загружаются непосредственно из плееров Blender Studio и Internet Archive. У коммерческих премьер кнопка открывает страницу правообладателя. Условия, в том числе подписка, указываются у источника.

## Обновление архива

Запуск из этой папки:

    python scripts/import_archive.py --limit 1000

Импорт читает публичный поисковый индекс Internet Archive. Он проверяет указанный источником открытый статус, длительность, тип материала и отсеивает повторяющиеся записи. Метка лицензии и ссылка на исходную карточку остаются у фильма. Эти метки получены из архива. Плееры и постеры используют адреса исходных площадок.

Новые премьеры добавляются в `catalogue.js`. Для запуска и проверки:

    node --check cinema.js
    node --check catalogue.js
    python -m http.server 18801 --bind 127.0.0.1

В запуске на Timeweb участвуют `index.html`, `styles.css`, два сценария, `archive-catalogue.json` и `assets/`. Python, серверная база и загрузка видеофайлов хостингу не нужны. В Mayday используется публичный HTTPS-адрес, разрешения мини-приложения можно оставить пустыми.
