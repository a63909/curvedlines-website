# Витрина Mayday

Русская версия доступна по `/`, английская по `/en/`. Заголовки, описания и карточки пересылки локализованы. Переключатель языка сохраняет раздел страницы и параметр `from=bankomet`. Он добавляет кнопку возврата к входу в Банкомёт. Переписка и бот на витрине демонстрационные.

Витрина находится на Timeweb. Публичный адрес mayday.colorchain.ru обслуживается существующим HTTPS-прокси Mayday с автоматическим продлением Let’s Encrypt.

Профиль открывается по https://mayday.colorchain.ru/invite/?id=<Mayday ID>, а вход из Банкомёта — по https://mayday.colorchain.ru/bankomet/#requestId=<запрос>. Оба адреса показывают витрину в браузере. На Android они также открываются в подписанном приложении STD после обновления. Есть английские версии обоих путей. Код запроса Банкомёта находится во фрагменте URL и в HTTP-запрос к витрине не попадает.

Приглашение в нарды открывает страницу `/nardy/#id=<Mayday ID>` или `/en/nardy/#id=<Mayday ID>`. Кнопка «Открыть вызов» ведёт в Mayday к подтверждению отправки приглашения на партию без ставки. Ссылка сохраняется при переключении языка и переходе к загрузкам. После установки и подтверждения номера получатель может вернуться по той же ссылке. «Сыграть с ИИ» открывает свободное лобби.

В шапке и подвале стоит логотип Mayday. Шапка, первый экран, кнопки и плашки оформлены по первой версии витрины. Шрифты Manrope и Cormorant Garamond загружаются локально. Знаки платформ находятся в `dist/assets/platforms/`.

Тексты находятся в `src/copy.mjs`, общий шаблон в `src/template.html`, поведение страницы в `src/page.mjs`. Сборка включает стили из `dist/style.css`, иконки, сценарий и настройки выпуска в страницы главной и приглашений. Браузер пробует загрузить шрифты после полной загрузки страницы. Если запрос занимает дольше трёх секунд, остаётся системный шрифт. Для статического хостинга достаточно `dist/`. После изменения `dist/release.mjs` повторно запустите сборку, чтобы обновить ссылки в страницах.

```powershell
node website/mayday-download/build.mjs
python -m http.server 18764 --bind 127.0.0.1 --directory website/mayday-download/dist
```

## Справка Mayday

Сборщик создаёт оглавление на `/help/` и `/en/help/`, а также статьи `getting-started/`, `network/`, `relay-operator/` и `mini-apps/` в каждом языке. Ссылки на справку добавлены в шапку и подвал витрины. Из статьи «Сеть Mayday» можно перейти к инструкции по запуску непубличного узла и выдаче приглашений.

Чтобы добавить статью, внесите её в обе языковые версии в `src/help.mjs`. Используйте одинаковые адреса и идентификаторы разделов для RU и EN, сверяйте названия кнопок с приложением и повторно запустите сборку. `src/render-help.mjs` генерирует оглавление, страницы и ссылки между языками.

## Загрузки и публикация

- **Windows x64.** Мастер MaydaySetup 0.3.0 позволяет выбрать папку и создаёт ярлыки на рабочем столе и в меню «Пуск». Установщик MSI доступен рядом с ним. Для подключения отсканируйте QR из Mayday на телефоне. [Документация клиента](../../app/mayday-desktop/README.md).
- **Android.** После одобрения публичного выпуска использовать `ops/release-android.ps1`. Он проверяет пакет и подпись STD, публикует APK и обновляет загрузки страниц RU/EN, включая приглашения и вход из Банкомёта. Постоянный адрес [скачивания APK](https://mayday.colorchain.ru/releases/mayday.apk) ведёт к текущему файлу. Сервер проверяет SHA-256 полной HTTPS-загрузки, затем удаляет прежние APK витрины.
- **Linux.** Готовой сборки нет. Текущий десктопный клиент использует WPF для Windows.
- **macOS.** После сборки отдельного клиента подписать приложение сертификатом Developer ID, заверить DMG в Apple и проверить запуск на Mac. Загрузить DMG по `dist/releases/mayday-macos-<версия>.dmg` или `mayday-macos-<universal|arm64|x64>-<версия>.dmg`. Заполнить `macRelease` в `dist/release.mjs` полями `filename`, `version`, `bytes`, `sha256`. Проверить скачивание и контрольную сумму. [Developer ID](https://developer.apple.com/developer-id/).
- **iPhone.** Проект `ios/ColorChainCompanion` поддерживает сборку без подписи. Для внешней беты подписать сборку, загрузить её в App Store Connect, пройти проверку TestFlight и проверить приглашение на iPhone. Указать проверенный адрес вида `https://testflight.apple.com/join/<код>` в `testFlightInvite`. [TestFlight](https://developer.apple.com/testflight/).
- Публичный адрес `https://mayday.colorchain.ru/`. Переход в действующем Банкомёте подключается после публикации проверенного Android APK. При выборе другого адреса обновить `SITE` в `build.mjs`, ссылки alternate/canonical в шаблоне и адрес в клиенте Банкомёта.

Android Intent открывает установленный пакет `com.example.tamarashadow.std` или страницу с `from=bankomet`. После установки «Вернуться в Банкомёт» открывает новый выбор входа. Android и Windows проверяются отдельными сценариями.

Для одобренной публичной сборки указать её порядковый номер и путь к APK. Вариант с `-VersionCode` собирает STD Release из текущей рабочей копии с профилем кошелька из `ops/android-release.properties` и сразу публикует результат.

```powershell
pwsh -File website/mayday-download/ops/release-android.ps1 -ReleaseNumber $releaseNumber -Apk $signedPublicApk -SshKey $identityFile
pwsh -File website/mayday-download/ops/release-android.ps1 -ReleaseNumber $releaseNumber -VersionCode $androidVersionCode -SshKey $identityFile
```

На сервере публикацию выполняет `/usr/local/sbin/mayday-publish-website-apk` из `ops/publish-android.py`. Команда `--plan` показывает текущий APK и устаревшие файлы витрины. Публикация сайта и обязательное обновление клиента используют разные настройки.

## Счётчик скачиваний

[Закрытая статистика Mayday](https://mayday.colorchain.ru/admin/downloads/) доступна администратору. Страница показывает число завершённых скачиваний и разбивку по платформам и версиям. Сервер пересчитывает данные примерно раз в десять секунд. Открытая страница обновляется автоматически. Для входа используются отдельные данные кабинета статистики.

Команда `mayday-download-counts` показывает ту же статистику в терминале. Для APK, EXE, MSI, ZIP и DMG счётчик складывает диапазоны байтов одной загрузки и засчитывает её один раз после передачи всего файла. Повторы диапазонов и HEAD-запросы счётчик пропускает. Журнал хранит длины ответов и случайный идентификатор загрузки без IP-адреса. Старые записи о завершённых скачиваниях продолжают учитываться. Счётчик охватывает загрузки через mayday.colorchain.ru.
